How to Get a YouTube Video Transcript — Step by Step

A transcript is the full text of everything spoken in a video, line by line, with the time each line appears. This guide shows you the fastest way to get one — using this free tool — and also the slower manual way inside YouTube itself.

Method 1: Use this tool (about 10 seconds)

  1. Copy the video link. Open the video on YouTube, tap Share and then Copy link. On a computer, you can copy the address from the browser's address bar. Links like youtube.com/watch?v=…, youtu.be/…, Shorts links and Live links all work.
  2. Paste it on the home page. Put the link in the box at the top and press Get Transcript.
  3. Choose the caption language. If the video has captions in more than one language, a language list appears. Pick the one you want — for example Hindi or English. "Auto" in the list means YouTube generated those captions automatically from the audio.
  4. (Optional) Translate. Use the Translate to option if you want the transcript in a different language than the original captions.
  5. Read, search, copy or download. Use the search box to find a word inside the transcript, click any timestamp to open the video at that exact moment, and use Copy, Download .txt or Download .srt to save the text.

Method 2: Inside YouTube (manual)

YouTube itself shows transcripts for many videos. On a computer, open the video, click the … (more) button below the title to expand the description, and choose Open transcript. The transcript panel opens next to the video. On the mobile app this option is limited and harder to copy from, which is why most people prefer a tool like this one — it also lets you download the transcript as a file, which YouTube does not offer.

Which file should you download?

.txt is plain text with timestamps — best for reading, notes, essays, blog research and studying. .srt is a subtitle file — use it if you edit videos and want to attach these subtitles in an editor like CapCut alternatives, Premiere Pro or YouTube Studio.

When it does not work

If you see "this video has no captions", the creator never added subtitles and YouTube did not auto-generate them — in that case no transcript exists to fetch. If you see a message that YouTube blocked the fetch, wait a minute and press Try Again; this is a temporary limit on YouTube's side. Private and age-restricted videos cannot be fetched by any public tool.

Tips for students and creators

Students: search the transcript for the exact term your teacher mentioned instead of re-watching the whole lecture. Creators: download your own video's transcript to write descriptions, chapters and blog posts faster. Everyone: auto-generated captions can contain spelling mistakes, especially with names — proofread before quoting them anywhere important.
